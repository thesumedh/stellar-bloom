# StellarBloom - Gasless Web3 Onboarding for Soroban Apps

[![StellarBloom CI](https://github.com/thesumedh/stellar-bloom/actions/workflows/ci.yml/badge.svg)](https://github.com/thesumedh/stellar-bloom/actions/workflows/ci.yml)

StellarBloom is a developer infrastructure platform that removes the biggest barrier in Web3: **gas fees and wallet friction**.

Built for Stellar smart contracts on Soroban, StellarBloom allows users to interact with decentralized apps without owning crypto or installing a wallet. **We are the Stripe for gasless Web3 onboarding on Soroban.**

> **Note:** This repository represents the **Level 4 - Black Belt** implementation for the Stellar Journey to Mastery program.

---

## 🚨 The Problem: The Onboarding Trap
Today, a new user must: Install a wallet → Buy tokens on an exchange → Transfer funds to the wallet → Understand gas fees → Send a transaction.

Result: A massive ~90% user drop-off before their first transaction.

## ✨ The Solution
StellarBloom abstracts away blockchain complexity by introducing a multi-tenant gasless onboarding layer. Instead of requiring users to pay gas, StellarBloom:
1. Receives a signed user request
2. Wraps it in a Soroban `FeeBumpTransaction`
3. Pays the network fee seamlessly through an enterprise Relayer
4. Submits it to the network

## 🚀 Level 4 Features: Developer Infrastructure
We have evolved beyond a single-dApp relayer into a full B2B Infrastructure Platform featuring:

1. **Multi-dApp Relayer API:** Developers can generate API keys and route transactions securely.
2. **Developer Dashboard:** A real-time analytics portal tracking XLM gas sponsored and Total Transactions per API Key.
3. **Gas Budget & Abuse Protection:** Global rate limiting (IP & Application level) implemented to ensure sustainable gas sponsorship.
4. **CI/CD Pipeline:** Automated GitHub Action workflows testing our Rust contracts and building our React dashboards on every push.

## Setup Instructions

### 1. Running the Relayer Backend (Multi-Tenant)

1. **Navigate to the relayer folder**
   ```bash
   cd relayer
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start the Relayer** (Runs on port 3000)
   ```bash
   npm start
   ```

### 2. Running the Infrastructure Portal & Demo

1. **Navigate to the frontend folder**
   ```bash
   cd stellar-bloom
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start the Development Server**
   ```bash
   npm run dev
   ```

4. **Toggle the Dashboard!**
   - Click "Developer Dashboard" to generate your first API Key.
   - Click "Live Demo" to experience the gasless end-user flow!
